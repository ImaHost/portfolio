# 장규현 — 포트폴리오

React·TypeScript 프론트엔드 개발 3년 차 개발자입니다. 최근에는 RAG 기반 AI 서비스의 검색·질의응답 백엔드와 관리자 화면을 함께 개발하고 있습니다.
UI/UX 구현과 최적화에 강점이 있고, Java·Python 백엔드와 연동하며 화면부터 API까지 함께 보는 개발을 지향합니다.

## 기술

- **프론트엔드**: React, TypeScript, Vite, Next.js, MUI, Tailwind
- **백엔드**: Python(FastAPI, Celery), Java(Spring, eGovFrame)
- **AI / 검색**: RAG, 하이브리드 검색(BM25 + Dense), Qdrant, bge-m3, Kiwi 형태소 분석, vLLM, Azure OpenAI, Gemini, Claude API
- **데이터 / 인프라**: PostgreSQL, Redis, Docker, Jenkins, GitLab, Azure
- **AI 협업 개발**: Claude Code, Cursor — 프로젝트 규칙 문서·전문 에이전트·작업 커맨드로 설계 문서와 코드를 일관되게 유지

## 이 저장소에 대해

네 프로젝트 모두 회사·발주기관의 자산이라 **소스 코드는 포함하지 않습니다.** 각 폴더에는 제가 맡은 범위, 설계와 처리 흐름, 해결한 문제, 성과, 화면을 정리했습니다.
화면 캡처는 로컬 개발 환경에서 시험 계정·공개 규정으로 찍은 것이며, 실제 사용자 데이터는 들어 있지 않습니다.
