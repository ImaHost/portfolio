## 쓰는 기술

- **프론트엔드**: React, TypeScript, Vite, Next.js, MUI, Tailwind
- **백엔드**: Python(FastAPI, Celery), Java(Spring, eGovFrame)
- **AI / 검색**: RAG, 하이브리드 검색(BM25 + Dense), Qdrant, bge-m3, Kiwi 형태소 분석, vLLM, Azure OpenAI, Gemini, Claude API
- **데이터 / 인프라**: PostgreSQL, Redis, Docker, Jenkins, GitLab, Azure
- **AI와 같이 개발하기**: Claude Code, Cursor — 프로젝트 규칙 문서와 전문 에이전트, 작업 커맨드를 두고 설계 문서와 코드를 같이 유지

실무 프로젝트는 회사·발주기관의 것이라 코드는 싣지 않았습니다. 대신 제가 맡은 범위, 설계와 처리 흐름, 해결한 문제, 화면을 정리했습니다. 화면은 시험 계정과 더미 데이터로 찍었고, 로고·고객사명·이름은 가렸습니다. 시연 페이지(`demo/`)만 예외로, 실제 화면을 재구성한 시연용 코드라 그대로 올렸습니다.
