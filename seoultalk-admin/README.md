|---|---|

## 2. 두 사이트를 한 일정에

| | 내부 서울톡 Admin | 외부 서울톡 Admin |
|---|---|---|
| 기반 | 더존 프레임워크 | 자체 솔루션 |
| 프론트엔드 | React 관리자 사이트 | React · TypeScript, Java 백엔드와 연동 |
| 사용자 | 서울시 내부 운영자 | 외부 기관 관리자 |

서로 다른 기술 기반의 두 솔루션을 같은 납기 안에서 개발해야 했습니다. 공통으로 쓸 수 있는 부분(화면 구성 패턴·API 호출 계층·상태 표기)을 먼저 정리해 두 사이트가 공유하게 하고, 프레임워크에 묶인 부분만 따로 구현해 납기 내 완료했습니다.
