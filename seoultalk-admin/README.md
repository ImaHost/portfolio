# 서울시 서울톡 RAG 관리자 사이트

| 항목 | 내용 |
|---|---|
| 기간 | 2025.10 – 2026.03 |
| 제품 | 서울시 시민 상담 서비스 '서울톡'의 RAG 기반 **내부·외부 관리자(Admin) 사이트** |
| 역할 | **프론트엔드 리드** — 내부·외부 두 사이트를 동시에 개발하며 일정과 인력 배분 조율. 외부 관리자 사이트는 직접 구현 |
| 스택 | React · TypeScript · Next.js 14 · MUI · Java 백엔드(백오피스·인증 서버) 연동 · Docker |

---

## 1. 두 사이트를 한 일정에

| | 내부 서울톡 Admin | 외부 서울톡 Admin |
|---|---|---|
| 기반 | 더존 프레임워크 | 자체 솔루션 |
| 프론트엔드 | React 관리자 사이트 | React · TypeScript · Next.js · MUI, Java 백엔드와 연동 |
| 사용자 | 서울시 내부 운영자 | 외부 기관 관리자 |

서로 다른 기술 기반의 두 솔루션을 같은 납기 안에서 개발해야 했습니다. 공통으로 쓸 수 있는 부분(화면 구성 패턴·API 호출 계층·상태 표기)을 먼저 정리해 두 사이트가 공유하게 하고, 프레임워크에 묶인 부분만 따로 구현해 납기 내 완료했습니다.

---

## 2. 외부 관리자 사이트 — 구현한 기능

| 메뉴 | 기능 |
|---|---|
| 모니터링 | 기간별 검색 건수·답변 만족도 현황. 기간 프리셋(오늘·이번달)과 셀렉박스 연동 |
| 검색현황 | 시민 질문·답변 목록과 상세, 소요시간·트랜잭션 ID 컬럼, 엑셀 다운로드 |
| 매뉴얼 관리 | RAG에 쓰는 매뉴얼 문서 등록·수정·삭제, 첨부파일 업로드·다운로드, 등록 진행 상태(진행중) 표시와 삭제 실패 안내, 삭제 후 페이지 위치 유지 |
| 수집통계 | 데이터 수집 현황 통계, 첫 진입 시 자동 조회 |
| 데이터 관리 설정 | 자동 삭제 주기 등 운영 설정(공통 코드 기반) |
| 카테고리·FAQ·공지 | 분류 체계와 공지·FAQ 관리 |
| 조직·사용자·권한·메뉴 | 기관 등록, 사용자·관리자 관리, 역할별 권한과 메뉴 매핑 |

- Next.js 서버 라우트(`/api/excel/*`)로 엑셀 생성을 서버 쪽에서 처리해 브라우저 부담을 줄였습니다.
- 로그인 5회 실패 시 5분 잠금, 관리자 전용 계정 분리 등 보안 요구사항을 반영했습니다.
- 등록·수정 직후 목록 재조회 지연(백엔드 색인 반영 시간)을 로딩 표시와 지연 조회로 처리해 "저장했는데 안 보임" 문의를 없앴습니다.
