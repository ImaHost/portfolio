프로젝트 시연

포트폴리오에 정리한 프로젝트의 실제 화면을 영상 대신 HTML · CSS · JS로 재구성해 재생합니다. 한국산업단지공단의 규정 검색 · 국회 대응 · 공시 작성은 회사 홈페이지용으로 만든 시연을 그대로 옮겼고, 나머지는 같은 방식으로 포트폴리오용으로 만들었습니다.

프로젝트와 서비스를 고르면 처음부터 재생되고, [크게 보기]로 화면을 가득 채워 볼 수 있습니다.
